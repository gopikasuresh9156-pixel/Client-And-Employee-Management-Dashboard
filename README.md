# Client and Employee Management Dashboard

An interactive Power BI dashboard designed to analyze and manage **client and employee information** in a single project. The dashboard contains two pages: **Client Management** and **Employee Management**.

### Page 1 – Client Management
This page provides insights into client details, projects, project values, active and completed projects, and outstanding payments. It helps users understand client performance and project status.

### Page 2 – Employee Management
This page provides insights into employee details, departments, designations, skills, experience, joining dates, and employment status. It helps in analyzing workforce information and employee distribution.

### Tools Used
- Power BI
- Excel
- Data Visualization
- Data Analysis

### Key Features
- Client and employee overview
- Interactive slicers and filters
- KPI cards
- Project and employee analysis
- Department and designation analysis
- Project status tracking
- Outstanding payment analysis
- Interactive charts and tables
